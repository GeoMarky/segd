# P190 model

`P190File` reads UKOOA P1/90 text. Header cards (`H`) are kept as strings. Point
records (`V`, `E`, `A`, `S`, `Z`, `C`, `T`) and receiver cards (`R`, three groups
per line) become:

- `shots`: structured array (shot point, easting, northing, depth, time, …)
- `receivers`: `float64` array shaped `(n_shots, n_groups, 3)`

`P190Factory` writes the same card types back out.
